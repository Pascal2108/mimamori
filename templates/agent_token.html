Connect the agent “{{ agent.name }}”

Copy the key now. It is shown only once: mimamori keeps only its public part. Anyone with it can send reports as this agent, so keep it out of git, issues and screenshots. If it gets lost or leaks, create a new one under Settings → Agents.

1. Put this in agent.env on the host

SERVER_URL is the address of mimamori as that host reaches it: the HTTPS address of your reverse proxy, or http://mimamori:8000 when the agent joins the server's Docker network. Every message between agent and server is signed and encrypted, so the key itself never travels over the network.

SERVER_URL={{ server_url }}
AGENT_KEY={{ token }}

2. Start the agent with docker-compose.agent.yml

List each drive of the host under devices. The agent needs to read the raw drives, so it starts as root inside its container, then splits: only the part that runs smartctl keeps root, the part that talks to the network runs as nobody without any capability. It opens no port. Remove SYS_ADMIN if the host has no NVMe drive, and make agent.env readable only by root. Then run docker compose -f docker-compose.agent.yml up -d.

services:
  mimamori-agent:
    image: {{ image }}
    container_name: mimamori-agent
    restart: unless-stopped
    env_file:
      - agent.env
    environment:
      AGENT_NAME: "{{ agent.name }}"
    devices:
      - /dev/sda
      - /dev/nvme0
    tmpfs:
      - /tmp:size=1m
    read_only: true
    cap_drop:
      - ALL
    cap_add:
      - SETUID                # to drop to an unprivileged user at start
      - SETGID
      - SYS_RAWIO
      - SYS_ADMIN
    security_opt:
      - no-new-privileges:true
    mem_limit: 64m
    pids_limit: 32
