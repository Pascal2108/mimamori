Updates

Agents whose host mounts its package list (see volumes in docker-compose.agent.yml) report the installed packages. mimamori checks them twice a day for missing security updates against the OSV vulnerability database (Debian, Ubuntu, Alpine). Drive firmware is compared with a list of known firmware bugs, without any outside connection.

This sends the names and versions of the installed packages and the system's release (for example Debian:12) to api.osv.dev, run by Google. No host names, addresses or drive data are sent. Off until you turn it on.
