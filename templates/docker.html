How often

The server asks the registry of each image (Docker Hub, GitHub, Quay, your own registry over HTTPS) which tags exist; for a followed tag such as latest only which image it points to, which does not count as a pull on Docker Hub. Only public images work: mimamori stores no registry passwords. The agents are not involved. Who gets a notification is set in Settings → Notifications (off by default).
